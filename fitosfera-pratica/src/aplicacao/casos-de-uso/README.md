# aplicacao/casos-de-uso

Uma classe por ação do usuário, cada uma recebendo pelo construtor só as portas de que precisa:

- `AdicionarPlantaAoJardim`, `RemoverPlantaDoJardim`, `RegistrarRega`
- `ListarJardimVirtual`, `ObterDetalhesDaPlanta`
- `ObterLeituraAmbiental`, `PesquisarEspecies`
- `AjustarPreferencias`, `ExecutarVerificacaoPeriodica`
